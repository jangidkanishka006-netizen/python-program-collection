
# Python Programs Collection

A collection of beginner-friendly Python programs.

## Programs

1. **Factorial** — Calculates the factorial of a non-negative integer.
2. **Fibonacci Series** — Prints the requested number of Fibonacci terms.
3. **Structure to Dictionary** — Converts a Student dataclass record into a dictionary.

## Technologies

- Python 3
- Dataclasses
- Basic loops, conditionals, and user input

## How to Run

Run each file using Python:

```bash
python factorial.py
python fibonacci.py
python structure_to_dictionary.py
```

## Learning Outcomes

- Using loops and conditional statements
- Taking input from users
- Working with Python dataclasses and dictionaries
